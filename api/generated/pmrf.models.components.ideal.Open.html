Open

class pmrf.models.components.ideal.Open(nports: int = 1, *, name: str | None = None, metadata: Any = None)

Bases: Model

A standard ideal open circuit load (gamma = 1.0).

This open does not have a reference impedance, since an ideal short circuit has the same S-parameters irrespective of the reference impedance.

Parameters:

nports (int) – The number of ports the open presents. Default is 1.

nports: int = 1
