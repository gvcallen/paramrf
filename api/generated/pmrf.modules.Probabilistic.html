Probabilistic

class pmrf.modules.Probabilistic(module: Any, distribution: Any, names: tuple[str, ...], space: Literal['raw', 'declared', 'physical'], *, name: str | None = None, metadata: Any = None)

Bases: Module, AbstractUnwrappable

A joint prior over named parameters of a tree, which it wraps unchanged.

Built by pmrf.prior() (ADR-0005). The parameters keep their names and stay parameters: names are resolved straight through this wrapper, as through Tied. The joint prior replaces the parameters’ own priors in pmrf.log_prior(). pmrf.resolve() keeps it, and pmrf.unwrap() drops it, as it drops every prior.

unwrap() → Any

Evaluates and returns the underlying unwrapped PyTree node.

Returns:

The resolved underlying value, assuming no wrapped subnodes exist.

distribution: AbstractDistribution

The joint distribution, over the vector of the parameters’ values in space. It is held frozen, so its arrays are not parameters.

module: Any

The wrapped tree, unchanged.

names: tuple[str, ...]

The parameter names, relative to module, in the order of the distribution’s vector.

space: Literal['raw', 'declared', 'physical']

'raw', 'declared' or 'physical'. 'raw' is the parameters’ raw space as it was when the prior was attached.

Type:

The space the distribution is over
