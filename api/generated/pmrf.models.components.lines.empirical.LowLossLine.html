LowLossLine

class pmrf.models.components.lines.empirical.LowLossLine(length: Any, zn: Any = 50.0, ep_eff: Any = 1.0, A: Any = 0.0, tand: Any = 0.0, f_ref: Any = 1000000000.0, *, name: str | None = None, metadata: Any = None)

Bases: AbstractUniformLine

Low-loss line defined by effective values.

The high-frequency, low-loss approximation of a lossy line. Its characteristic impedance is exactly real and its attenuation separates into conductor and dielectric parts. It has no per-unit-length immittance, because \(\sqrt{Z'/Y'}\) is never exactly real once there is loss.

Mathematical Formulation

\[Z_c(\omega) = z_n \qquad \gamma(\omega) = \alpha_c(\omega) + \alpha_d(\omega) + j\omega\frac{\sqrt{\varepsilon_{eff}}}{c_0}\]

with

\[\alpha_c(\omega) = \frac{\ln 10}{20} A \sqrt{\frac{\omega}{\omega_{ref}}} \qquad \alpha_d(\omega) = \frac{\omega \sqrt{\varepsilon_{eff}} \tan\delta}{2 c_0}.\]

Example

import pmrf as prf
from pmrf.models import LowLossLine

line = LowLossLine(zn=50.0, ep_eff=2.1, A=0.05, tand=2e-4, length=1.0)

freq = prf.Frequency(start=1, stop=1000, npoints=101, unit='mhz')
s = line.s(freq)

References

  • f_ref (Param, default=1e9) – Reference frequency of A in Hz.
