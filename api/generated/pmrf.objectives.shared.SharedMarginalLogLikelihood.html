SharedMarginalLogLikelihood

class pmrf.objectives.shared.SharedMarginalLogLikelihood(datasets, latents)

Bases: AbstractTerm

Score datasets whose event-space discrepancies share latent functions.

The datasets are (MarginalLogLikelihood, Frequency) pairs, each with no local discrepancy. All kernel inputs use the first frequency’s unit. Latent rows are ordered by latent, then flattened kernel batch index, then frequency. A kernel row exists on the union of the fit frequency grids.

Parameters:

  • datasets (tuple[tuple[MarginalLogLikelihood, Frequency], ...]) – Per-dataset likelihood and fixed fit grid. Each likelihood must have Gaussian noise and no local or orthogonal discrepancy.

  • latents (tuple[SharedLatent, ...]) – Kernel and mixing pairs shared by all datasets.

predict_discrepancy(model: PyTree, new_frequency: Frequency, *, dataset: int | None = None, prediction_event: Array | None = None) → AbstractDistribution

Predict event-space discrepancy for a fit dataset or a new prediction.

Pass dataset for a fitted dataset, or prediction_event for a new device on new_frequency. The returned joint Gaussian is flattened in event-block then frequency order.

Parameters:

  • model (PyTree) – Model shared by the fit dataset predictors.

  • new_frequency (Frequency) – Grid for the discrepancy posterior, in any unit.

  • dataset (int, optional) – Index of a dataset in the fit. Its predictor supplies the new event-space prediction.

  • prediction_event (jnp.ndarray, optional) – Event-space prediction for a new device that shares the latents. Supply this or dataset, but not both.

Returns:

Joint Gaussian over flattened event blocks and frequency, without measurement noise.

Return type:

dist.AbstractDistribution
