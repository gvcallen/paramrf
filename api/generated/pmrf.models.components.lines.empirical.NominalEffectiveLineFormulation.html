NominalEffectiveLineFormulation

class pmrf.models.components.lines.empirical.NominalEffectiveLineFormulation(*, name: str | None = None, metadata: Any = None)

Bases: AbstractEffectiveLineFormulation

The RLGC line built directly from the nominal per-unit-length quantities.

This is the default formulation of PhysicalLine and DatasheetLine, deliberately: CAD “physical” lines, such as ADS/AWR TLINP and scikit-rf’s DefinedAEpTandZ0 by default, use a frequency-flat permittivity in the same way. It is not causal. \(G'\) is exactly proportional to \(\omega\) with no Kramers-Kronig partner in \(C'\), and the skin-effect \(R'\) has no matching internal inductance. For a causal line, use FirstOrderEffectiveLineFormulation.

Mathematical Formulation

\[Z' = R'_n + j\omega L'_n \qquad Y' = G'_n + j\omega C'_n\]

with the nominal quantities of EffectiveValues. To first order in \(R'/(\omega L')\) and \(G'/(\omega C')\) this is LowLossLine.

References

Pozar, D. M. (2011). Microwave Engineering (4th ed.), Sections 2.1 and 2.7. Wiley.
