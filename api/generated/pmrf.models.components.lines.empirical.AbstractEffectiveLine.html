AbstractEffectiveLine

class pmrf.models.components.lines.empirical.AbstractEffectiveLine(length: Any, *, name: str | None = None, metadata: Any = None)

Bases: AbstractImmittanceLine

Abstract base class for an effective-value line.

An effective-value line is parameterized by effective values instead of by geometry and materials. Derived classes map their own parameters to EffectiveValues in effective_values(), and turn them into the per-unit-length immittance in immittance().

Parameters:

length (Param) – Physical length of the line in meters.

abstractmethod effective_values() → EffectiveValues

The effective values of the line.

Returns:

The nominal impedance, effective permittivity, conductor attenuation, loss tangent and their reference frequency.

Return type:

EffectiveValues
