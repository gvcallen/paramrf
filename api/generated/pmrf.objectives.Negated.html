Negated

class pmrf.objectives.Negated(evaluator: AbstractEvaluator, *, name: str | None = None, metadata: Any = None)

Bases: AbstractEvaluator

Computes the negative of another evaluator.

This is a general sign flip: it reads nothing from the wrapped evaluator beyond calling it, so it works for any pmrf.objectives.evaluators.AbstractEvaluator.

Its most common use is turning a log-likelihood into a quantity to minimize, for example wrapping pmrf.objectives.evaluators.MarginalLogLikelihood or pmrf.objectives.evaluators.GibbsMarginalLogLikelihood for Maximum Likelihood Estimation.
