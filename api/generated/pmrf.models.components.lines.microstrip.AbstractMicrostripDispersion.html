AbstractMicrostripDispersion

class pmrf.models.components.lines.microstrip.AbstractMicrostripDispersion

Bases: Module

Abstract modal-dispersion formulation for an inhomogeneous microstrip.

abstractmethod disperse(freq: Frequency, *, ep_eff_0, zc_0, ep_r, w_eff, h) → tuple[Array, Array]

Return frequency-dependent \((\varepsilon_e, Z_c)\).

Parameters:

  • freq (Frequency) – The frequency axis.

  • ep_eff_0 (jnp.ndarray) – Quasi-static complex effective relative permittivity.

  • zc_0 (jnp.ndarray) – Quasi-static characteristic impedance in ohms.

  • ep_r (jnp.ndarray) – Complex relative permittivity of the substrate.

  • w_eff (jnp.ndarray) – Electromagnetic effective conductor width in meters.

  • h (ArrayLike) – Substrate height in meters.

Returns:

The dispersed effective permittivity and characteristic impedance.

Return type:

tuple of jnp.ndarray
